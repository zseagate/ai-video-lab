# 00 概念卡

## 一句话

> 清晨六点半，街角咖啡馆的店员把第一杯咖啡留给一个总迟到的人；雨落下，灯还亮着。

## 给谁看

- 城市里独自通勤、经常迟到、但仍在认真生活的人
- 喜欢小店、手冲咖啡、雨夜街景的 20–35 岁受众

## 什么场合

- 咖啡馆品牌态度短片
- 课程 Demo / 工作坊示范片
- 竖版短视频的 16:9 母版

## 记住哪一句

> **晚到也算到，热着就好。**

## 情绪曲线

| 时间 | 情绪 | 功能 |
|---|---|---|
| 0–3s | 安静、清晨 | Hook：用一个具体时间建立画面 |
| 3–6s | 期待 | 第一杯咖啡，留给谁 |
| 6–9s | 轻微失落 | 看门、看钟，等待 |
| 9–12s | 转折 | 下雨，时间变慢 |
| 12–15s | 温柔 | 把名字写在杯套上 |
| 15–18s | 坚定 | 雨里守着两杯热咖啡 |
| 18–21s | 释放 | 主题句出现 |
| 21–24s | 收束 | 灯还亮着，明天早点来 |

## 视觉方向

- 扁平矢量 + 轻微颗粒 + 暖色灯光
- 主色：深青 `#143A3A`、奶油 `#F6E7CE`、琥珀 `#F2B56B`、砖红 `#D65A4A`
- 两个场景：
  1. 清晨咖啡馆内景：木柜台、玻璃窗、吊灯、咖啡机、蒸汽
  2. 雨夜街角外景：店招、雨棚、路灯、湿地面反光、两杯咖啡

## 角色

- 小满，24 岁，咖啡馆店员
- 黑色短发，奶油色衬衫，砖红色围裙，小银色耳钉
- 性格：话不多，记得熟客的口味
