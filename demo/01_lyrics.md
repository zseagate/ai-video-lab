# 01 歌词

## 结构（24 秒）

```
[Hook]    0–6s    2 句
[Verse]   6–15s   2 句
[Chorus]  15–21s  2 句
[CTA]     21–24s  1 句
```

## 歌词

```
[Hook]
清晨六点半 街角灯还亮
第一杯咖啡 等一个晚到的人

[Verse]
雨点敲着窗 秒针走得慢
我把你的名字 写在杯套上

[Chorus]
晚到也算到 热着就好
街角这盏灯 替你留着

[CTA]
明天 早点来
```

## 自检

- [x] 第一句有具体时间 + 画面
- [x] 记忆点不超过 12 字：「晚到也算到，热着就好」
- [x] 没有 PPT 词
- [x] 每句只讲一件事
- [x] 押韵自然，不强行押韵
- [x] 没有原案例歌词、地名、品牌、方言梗
- [x] 念白总时长约 18 秒，留出 2 秒开场和 4 秒收尾

## 备注

正式版把念白替换为 Suno 人声时，保持同样的断句和重音位置。  
`[Hook]` 的第 2 句和 `[Chorus]` 的第 1 句是记忆点，混音时可略微提高人声 1–2 dB。
