# 资产护照（Asset Passport）

> 用法：每个角色/场景/道具一份。写完后**逐字复制**到镜头提示词，只改动作/机位。
> 原则：写"可被画出来"的东西，不写"很酷/很高级/很震撼"。

---

## 一、角色护照

### 基本信息

| 项 | 内容 |
|---|---|
| 角色 ID | （英文小写，如 master） |
| 角色名 | （如 师父） |
| 物种/年龄感 | |
| 定位 | （主角/配角/群像） |
| 出现镜头 | |

### 视觉描述（9 项）

```
【脸型】
【黑眼圈/眼睛】
【表情习惯】
【发型】
【服装】
【配饰】
【体型/姿态】
【常用道具】
【材质/风格】
```

### 参考图

| 角度 | 文件 | 版本 | 备注 |
|---|---|---|---|
| 正面半身 | | | 主参考 |
| 正面全身 | | | 服装/比例 |
| 3/4 侧脸 | | | 表情/光影 |
| 背面 | | | 可选 |

### 一致性检查

- [ ] 三张图肉眼像同一个人；
- [ ] 服装颜色/材质一致；
- [ ] 黑眼圈形状一致；
- [ ] 配饰位置一致；
- [ ] 体型比例一致。

## 四、示例：师父（可直接改）

```
【角色 ID】master
【物种/年龄感】雄性大熊猫，约 40 岁拟人化
【脸型】圆脸，颧骨略宽，黑眼圈对称
【黑眼圈/眼睛】黑眼圈边缘清晰，眼角有轻微皱纹，眼神沉稳
【表情习惯】平时微皱眉，讲到关键处挑眉，偶尔嘴角上扬
【发型】短黑发，鬓角略白
【服装】灰黑色做旧夹克（灯芯绒领），白色圆领 T 恤，军绿色工装裤，黑色短靴
【配饰】无项链；右手常持黑色麦克风
【体型/姿态】偏壮，肩背厚，站姿稳，走路慢
【常用道具】盖碗茶、麦克风
【材质/风格】毛发细腻，布料有磨损纹理，3D 动画电影质感
```

## 五、示例：茶馆（可直接改）

```
【场景 ID】teahouse
【空间结构】老成都茶馆，木质梁柱，方桌长凳，前方小舞台，左侧入口
【主色】暖黄、深棕、青绿
【光源】纸灯笼暖光 + 窗外冷光，侧逆光，桌面有暖色反光
【关键道具】盖碗茶、长嘴铜壶、竹椅、戏台鼓、布帘
【材质】木头磨损、砖墙、布帘、轻微烟雾
【天气/氛围】傍晚，烟火气，群众低声交谈
```

## 六、一致性铁律

1. 每个镜头提示词**逐字复制**护照，不改写；
2. 只改动作/机位/场景/情绪，不改长相/服装/材质；
3. 同一角色所有镜头用同一张主参考图；
4. 服装变化必须建新版本（如 `master_v2_jacket`）；
5. 场景至少 2 个机位，避免所有镜头一个角度；
6. 生成前做"三图一致性测试"：同一提示词跑 3 次，看是否像同一人；
7. 参考图命名规范，不要用 `1.png`、`final.png`。
