## 二、60–90 秒结构

```
[Intro / Hook]（0–8s）
（写 1–2 句，问题/反差/画面）

[Verse 1]（8–32s）
（写 4–8 句，具体场景/痛点）

[Chorus]（32–56s）
（写 2–4 句，主张/行动/可重复）

[Verse 2 / Bridge]（56–72s）
（写 2–4 句，换角色/视角）

[Outro / CTA]（72–90s）
（写 1–2 句，落到行动）
```

---

## 三、20–30 秒结构

```
[Hook]（0–6s，2 句）
[Verse]（6–18s，4 句）
[Chorus]（18–26s，1–2 句）
[CTA]（26–30s，1 句）
```

---

## 四、写作检查

- [ ] 第一句能在 3 秒内让人想听第二句
- [ ] 有一句能被复述（≤12 字）
- [ ] 没有"赋能/闭环/抓手/生态位"等 PPT 词
- [ ] 每句只讲一件事
- [ ] 押韵自然，不为了押韵改病句
- [ ] 方言只做调味，外地人也能听懂
- [ ] 活动信息只出现一次，且在后半段
- [ ] 读一遍不超过目标时长（中文 Rap 约 4–6 字/秒）

---

## 五、押韵速查（中文 Rap）

| 韵脚 | 例字 | 适合 |
|---|---|---|
| a | 茶/话/家/耍/大 | 开场、轻松 |
| ai | 来/开/台/快/卖 | 行动、副歌 |
| an | 天/前/年/变/见 | 叙事、收束 |
| ao | 少/好/跑/老/道 | 经验、江湖 |
| i | 起/里/你/底/利 | 细节、对话 |
| ing | 听/清/行/明/定 | 态度、总结 |
| ou | 手/口/走/守/酒 | 动作、底线 |
| u | 路/数/住/步/谱 | 主题、副歌 |

> 不要每句都押；两两押、隔句押更自然。

## 六、示例：活动主题曲（60 秒）

```

[Verse 1]

新模型一出 又要重来
老板问我 能不能快一点

[Chorus]
来嘛 来嘛 成都见真章
新招式旧功夫 坐一桌商量

[Verse 2]
老师傅的手 新人的眼
一个敢想 一个敢验
舞台再亮 不如现场
落地那一秒 才算数

[Outro]
10 月 24 成都见
茶还热着 你来不来
```
