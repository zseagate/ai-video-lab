# QC 清单（发布前逐项打勾）

> 用法：每完成一版，复制一份，改名 `QC_项目名_v01.md`。
> 规则：Q0–Q6 任何一项不过，不进下一阶段。

---

## Q0 概念

- [ ] 一句话能说清"给谁看、什么场合、记住哪句话"
- [ ] 有一个明确的 CTA（报名/到场/关注/购买）
- [ ] 参考片 ≤ 3 支，风格不打架
- [ ] 已确认时长/画幅/平台

## Q1 歌词与音乐

- [ ] 3 秒内有钩子
- [ ] 有一句可复述的记忆点（≤12 字）
- [ ] 歌词与节拍对得上
- [ ] 人声清晰，伴奏不盖人声
- [ ] 没有抄袭/洗稿
- [ ] Suno/音乐商用授权确认
- [ ] 已导出 vocal + instrumental

## Q2 分镜与资产

- [ ] 每个镜头一个主动作
- [ ] 镜头卡六要素齐全
- [ ] 角色护照逐字一致
- [ ] 角色三图一致（正面/全身/侧脸）
- [ ] 场景至少 2 个机位
- [ ] 没有"模型做不到"的镜头
- [ ] 镜头总数/时长在预算内

## Q3 生成

- [ ] 每个镜头至少 1 个可用 take
- [ ] 角色没有换脸/换衣/换年龄
- [ ] 运镜方向与分镜一致
- [ ] 没有闪烁/扭曲/多指/融合
- [ ] 口型镜头比例 ≤ 30%
- [ ] 单镜头重抽 ≤ 3 次（超出已改方案）
- [ ] 成本在预算内

## Q4 剪辑

- [ ] 音画对齐
- [ ] 切点落在乐句/鼓点
- [ ] 镜头时长有变化，不拖沓
- [ ] 转场克制，硬切为主
- [ ] 实拍与 AI 片段色温匹配
- [ ] 没有黑帧/夹帧/重复帧
- [ ] 结尾有落点，不突然结束

## Q5 字幕与声音

- [ ] 字幕无错别字
- [ ] 字幕不挡脸、不超过两行
- [ ] 关键词高亮统一
- [ ] 字幕与歌词同步
- [ ] 音量均衡，人声约 -14 LUFS
- [ ] 音效不抢戏
- [ ] 静音观看也能看懂

## Q6 包装与合规

- [ ] 封面 3:4 / 9:16，手机能看清
- [ ] 标题 ≤20 字，不标题党
- [ ] 文案 3 行以内 + CTA
- [ ] 标签 3–5 个
- [ ] 文件命名规范
- [ ] 角色不撞知名 IP
- [ ] 真人/实拍有授权
- [ ] 字体/音效可商用
- [ ] 已加"AI 生成"显式标识
- [ ] 已保留生成记录/元数据
- [ ] 平台 AI 声明已勾选
- [ ] 无绝对化用语/虚假效果

## 交付前最后 5 分钟

- [ ] 用手机看一遍（不是只看电脑）
- [ ] 戴耳机听一遍
- [ ] 静音看一遍
- [ ] 发给一个不知情的人看，问"你记住了什么"
- [ ] 确认最终文件名/版本号
