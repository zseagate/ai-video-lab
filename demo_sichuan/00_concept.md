# 00 概念卡：一碗茶，慢慢摆

## 一句话

> 雨夜老茶馆，年轻川剧变脸演员小禾，在盖碗茶、火锅和锣鼓之间，找回自己的节奏。

- 不碰「熊猫 Rap」本体，也不复用原案例的角色、歌词、品牌或活动标识。
- 用同一条流水线做一个全新的 30 秒川味变体，证明方法论可复制。

## 情绪曲线

| 时间 | 情绪 | 功能 |
|---|---|---|
| 0–5s | 安静、潮湿 | Hook：雨夜茶馆，盖碗茶冒热气 |
| 5–10s | 松弛、亲切 | 四川方言进入，龙门阵开场 |
| 10–15s | 惊艳、热闹 | 变脸，红黑金脸谱连续切换 |
| 15–20s | 滚烫、烟火 | 火锅红汤、椒麻、蒸汽 |
| 20–25s | 释放、自在 | 雨巷红灯笼，小禾和伙伴们笑着走 |
| 25–30s | 收束、记忆点 | 标题卡：一碗茶，慢慢摆 |

## 视觉方向

- 扁平矢量 + 纸张颗粒 + 轻微手持感
- 主色：川剧红 `#C53A2F`、墨黑 `#171313`、戏金 `#D7A24A`、雨夜青 `#16323A`、椒红 `#D94B35`
- 光线：茶馆暖黄、雨夜青蓝、火锅红橙、舞台顶光
- 构图：16:9，1280×720，30fps，成片 30 秒

## 角色

- **小禾**，24 岁，川剧变脸学徒
- 短黑发，红黑戏服，金色脸谱，耳后一颗小痣
- 性格：台上利落，台下慢热；不赶时间，按自己的节奏来
- 只出现这 1 个主要角色；群众只做剪影，不给正脸

## 场景

1. 雨夜老茶馆外景：青瓦、木窗、红灯笼、竹椅、盖碗茶
2. 茶馆内桌：盖碗茶、木桌、雨窗、手部特写
3. 川剧小舞台：红幕、锣鼓、脸谱、变脸瞬间
4. 火锅桌：红汤、辣椒、花椒、毛肚、蒸汽
5. 雨巷：青石板、红灯笼、湿地面反光、伙伴剪影
6. 收尾卡：标题、副标题、流水线标注
