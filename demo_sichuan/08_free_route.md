# 08 免费官方路线作战表

> 目的：用不花钱的官方入口跑通「AI 写词 → Suno 出歌 → AI 视频出 4–5 个镜头 → 剪映拼装」的完整链路。
> ComfyUI 继续保留为本地练手 / 备用首帧 / 关键帧测试，不再作为最终主视觉生产线。

## 一句话结论

这次不用 **ComfyUI + SD1.5** 当主路线。最终 Demo 用 **即梦网页版** 出真视频镜头；ComfyUI 只在免费积分不够时当图生视频首帧兜底。

## 工具分工

| 环节 | 工具 | 用途 | 成本 |
|---|---|---|---|
| 写词 / 写分镜 / 写提示词 | Doubao-Seed-Evolving | 4 句川味歌词、S01–S06 分镜、镜头提示词、负面提示词 | 0 |
| 音乐 | Suno | 每日免费积分出 1–2 首 30 秒内歌曲 | 0 |
| 视频镜头 | 即梦网页版 | Seedance 同源引擎，5 秒镜头，官方免费入口 | 0 |
| 剪辑 / 字幕 / 调色 | CapCut / 剪映 | 拼装 4–5 镜 + 字幕 + 调色 + 导出 | 0 |
| 本地兜底 | ComfyUI + SD1.5 | 首帧图、关键帧测试、离线练习 | 0 |

## 镜头规划

1. S01 雨夜老茶馆外景：缓慢推近，雨滴、灯笼、蒸汽
2. S02 盖碗茶特写：揭盖、蒸汽旋转、雨窗散景
3. S03 川剧变脸舞台：扇面开合、脸谱快切、锣鼓
4. S04 火锅红汤微距：红汤翻滚、筷子夹毛肚、辣椒油反光
5. S05 雨巷红灯笼：跟拍、湿地反光、雨丝
6. S06 标题卡：用剪映/CapCut 直接在片尾做，优先不耗视频额度

## 执行顺序

### 早上
1. 注册即梦网页版，领取每日积分。
2. 用 Doubao-Seed-Evolving 写：
   - 4 句川味歌词
   - 6 个分镜提示词
   - 镜头负面提示词
3. 用 Suno 出 1–2 首候选歌。

### 下午
1. 在即梦生成 S01–S05。
2. 如果额度不够：
   - 等第二天积分继续补镜；或
   - 用 ComfyUI 出首帧图，走图生视频。
3. 把镜头落到：`demo_sichuan/assets/seedance/`

### 傍晚
1. 用 CapCut 拼装。
2. 加字幕、调色、卡点。
3. 导出成片并做 QC。

## 交付标准

- 成片 30 秒左右
- 4–5 个真实 AI 视频镜头
- 有字幕、调色、节奏感
- 不出现熊猫 Rap、原案例、品牌/活动标识
- 明确说明这是「零成本跑通完整链路」的版本
